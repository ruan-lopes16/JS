Arrays and Objects - Exercise

The results of the scripts are all in the console. Press F12 to see the results.

To see the other exercises in the console, uncomment the scripts.

Exercise 1

Basic Array Manipulation

Create a function that takes an array of numbers and returns a new array containing only even numbers, using forEach and push.

Exercise 2

Name Cleansing

Create a function that receives an array of names with extra spaces and returns the names cleaned up and in reverse order using trim, reverse, and array methods.

Exercise 3

Inventory Manager

Create a stock object with product properties. Implement functions to:

    Add a new product
    Remove a product
    List all keys (Object.keys)
    List all values (Object.values)

Exercise 4

Formatting Phone Numbers

Create a function that receives an array of phone numbers (strings) and formats them all using padStart, slice, and split.

Exercise 5

Product Analysis

Given an array of objects representing products, use forEach and destructuring to extract and display only the name and price of each product.

Exercise 6

Tag System

Create a function that receives a string of tags separated by commas, processes it using split, trim, map, and returns a clean array without duplicates.
