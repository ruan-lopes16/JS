Arrays and Objects - Exercise

The results of the scripts are all in the console. Press F12 to see the results.

To see the other exercises in the console, uncomment the scripts.

Exercise 1

Basic Array Manipulation

Create a function that takes an array of numbers and returns a new array containing only even numbers, using forEach and push.

Exercise 2

Name Cleansing

Create a function that receives an array of names with extra spaces and returns the names cleaned up and in reverse order using trim, reverse, and array methods.

Exercise 3

Inventory Manager

Create a stock object with product properties. Implement functions to:

    Add a new product
    Remove a product
    List all keys (Object.keys)
    List all values (Object.values)

Exercise 4

Formatting Phone Numbers

Create a function that receives an array of phone numbers (strings) and formats them all using padStart, slice, and split.

Exercise 5

Product Analysis

Given an array of objects representing products, use forEach and destructuring to extract and display only the name and price of each product.

Exercise 6

Tag System

Create a function that receives a string of tags separated by commas, processes it using split, trim, map, and returns a clean array without duplicates.

Exercise 7

Schedule Combiner

Use the rest operator (...) to create a function that receives multiple schedules and combines them all into a single array using join to create a final string.

Exercise 8

List of Services with Rest

Create a function that receives the first service as a normal parameter and the rest using the rest operator. Return an object with the main service and the additional services.

Exercise 9

JSON Conversor

Create a system that:
- Receives customer data as objects
- Converts to JSON (JSON.stringify)
- Simulates saving
- Retrieves and converts back (JSON.parse)
- Uses destructuring to extract specific information

Exercise 10

Complete Management System

Create a mini-system for AC Beauty that combines ALL concepts:
- Array of objects (customers/services)
- Use for...of to iterate
- Destructuring in arrays and objects
- Methods: filter, includes, slice, indexOf
- Convert to JSON and back
- Manipulate strings with split, join, repeat
